# Ui Audit

Inspect rendered screens at representative mobile and desktop widths and important interaction states. If only source or screenshots are available, identify what cannot be verified interactively.

Evaluate hierarchy, spacing, typography, responsive behavior, accessibility, contrast, component consistency, density, empty/loading/error states, interaction clarity, visual noise, layout repetition and generic AI patterns. Tie every finding to an element, viewport/state, observed consequence and concrete correction. Distinguish blockers from polish; do not infer accessible behavior from appearance alone.

Return a prioritized repair list with affected components and visual evidence. Preserve what already works. If implementation is requested, route into design-ui, then taste and automatic revision; an audit-only request ends with findings. Do not fabricate screenshots, metrics or browser checks.
