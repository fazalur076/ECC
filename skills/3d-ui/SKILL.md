# 3D Ui

Before using 3D explicitly answer: What does 3D improve here? Valid reasons include product visualization, storytelling, spatial interaction, brand identity, immersive hero, spatial/data understanding and meaningful delight. “3D looks premium” is insufficient; prefer a simpler representation when it serves the same purpose.

Inspect the existing stack and verify current library APIs from installed sources or official documentation. Set bundle, GPU/frame-time, mobile and battery budgets. Plan loading, asset compression, responsive sizing, device-pixel-ratio limits, context loss, cleanup/disposal and pause behavior offscreen or in background tabs.

Provide a useful static fallback, accessible semantic content and keyboard-operable equivalent controls. Respect reduced motion and avoid withholding essential information inside a canvas. Load expensive scenes only when needed and measure on representative constrained hardware or clearly disclose the testing limit.

Implement the smallest scene that fulfills the reason; connect motion-ui for interaction continuity and design-system for consistency. Run taste, automatically revise gratuitous or distracting effects, then verify responsive layout, accessibility, performance and final rendered behavior.
